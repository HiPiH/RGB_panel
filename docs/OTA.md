# Обновление по воздуху

Плата принимает новую прошивку по сети, кабель для этого не нужен. Таблица
разделов `min_spiffs.csv` держит два раздела приложения: обновление пишется во
второй, и загрузчик переключается на него только после успешной проверки. Если
заливка оборвётся, плата останется на прежней прошивке.

## Что нужно один раз

1. Вписать пароль в `.env`:

```
OTA_PASSWORD=свой-пароль
```

2. Залить прошивку по кабелю. С этого момента кабель больше не нужен.

Без пароля обновление по воздуху не включается совсем. Открытая заливка в
локальной сети означала бы, что любой в этой сети может залить в панель что
угодно, поэтому пустой пароль трактуется как «выключено», а не как «без
проверки». В логе платы это видно строкой про выключенное обновление.

## Как заливать

```
pio run -e esp32dev-ota -t upload
pio run -e esp32dev-ota -t upload --upload-port 192.168.1.42
```

Первая команда ищет плату по имени `rgb-panel.local`. Windows разрешает такие
имена не всегда, и тогда работает вторая: адрес платы виден в её логе и в
списке клиентов роутера.

Пароль подставляется автоматически. Этим занимается `scripts/ota_auth.py`,
и он обязан быть post-скриптом: флаги espota платформа задаёт через `env.Replace`
уже после pre-скриптов, поэтому пароль, добавленный раньше, просто теряется и
заливка падает на аутентификации. В `platformio.ini` пароля нет, в git он не
попадает.

## Что видно на панели

Экрана у стенда нет, поэтому ход заливки показывает сама панель:

| Картинка | Что происходит |
| --- | --- |
| Панель гаснет | заливка началась |
| Синяя полоса растёт | процент записанного |
| Панель зелёная | записано, идёт перезагрузка |
| Панель красная | заливка сорвалась, работает прежняя прошивка |

Полоса перерисовывается только на смене процента: вывод на ленту стоит 7.7 мс,
и на каждом пакете заливки это заметно тормозило бы обновление.

Пока идёт заливка, ни демо, ни поток кадров не рисуются. Кадры, пришедшие в
это время, просто теряются, это нормально.

## Диагностика

| Симптом | Причина |
| --- | --- |
| `No response from the ESP` | плата не в сети либо указано неразрешимое имя, пробуйте по адресу |
| `Authentication Failed` | пароль в `.env` и пароль на плате разошлись, перезалейте по кабелю |
| В логе платы `OTA: пароль не задан` | `OTA_PASSWORD` пуст в момент сборки прошивки |
| Заливка идёт и обрывается | слабый сигнал, смотрите RSSI в логе платы |

Порт заливки 3232, он занят только на время обновления. Порт кадров 4210
работает как обычно.
