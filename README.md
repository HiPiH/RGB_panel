# RGB Panel

Адресная светодиодная RGB-панель на ESP32 с удалённым управлением.

## Текущее состояние

Спринт 1 — демонстрационный стенд. После подачи питания панель целиком
заливается одним цветом и непрерывно проходит маршрут
чёрный → красный → весь спектр → белый → чёрный. Задержка между соседними
цветами настраивается.

Спринт 2 — подключение к Wi-Fi. Имя сети и пароль берутся из `.env`, плата
подключается к точке доступа и сама восстанавливает связь после обрыва.
Анимация при этом не прерывается.

Спринт 3 — приём кадров по UDP. Пока потока нет, играет демо. Как только
приходят кадры 16 × 16, панель показывает их и возвращается к демо через две
секунды тишины. Проверено на 20 и 60 кадрах в секунду без потерь.

## Структура

| Путь | Назначение |
| --- | --- |
| `platformio.ini` | окружение сборки, зависимости |
| `include/Config.h` | пины, геометрия панели, лимиты питания, параметры демо |
| `include/DemoSequence.h`, `src/DemoSequence.cpp` | расчёт цвета демо-последовательности |
| `include/WiFiLink.h`, `src/WiFiLink.cpp` | подключение к сети и переподключение |
| `include/FrameProtocol.h` | разбор датаграммы с кадром |
| `include/FrameReceiver.h`, `src/FrameReceiver.cpp` | приём кадров и счётчики |
| `src/main.cpp` | инициализация FastLED и главный цикл |
| `scripts/load_env.py` | переносит параметры сети из `.env` в прошивку на сборке |
| `scripts/send_frames.py` | отправитель пробных кадров для проверки потока |
| `.env` | имя сети и пароль, в git не попадает |
| `docs/HARDWARE.md` | схема подключения и требования к питанию |
| `docs/WIFI.md` | параметры сети, поведение подключения, диагностика |
| `docs/PROTOCOL.md` | формат UDP-кадров и поведение платы, план спринта 3 |
| `docs/SPRINTS.md` | журнал спринтов: задачи, проблемы, решения |

## Сборка и прошивка

```
pio run                  # сборка
pio run -t upload        # прошивка
pio device monitor       # лог, 115200 бод
```

Если вывод команды перенаправляется в файл или в конвейер, на Windows нужна
переменная `PYTHONIOENCODING=utf-8`, иначе прогресс-бар esptool роняет заливку
на середине.

Поток кадров на панель:

```
python scripts/send_frames.py <IP платы>
```

IP платы виден в её логе. Формат датаграммы и поведение приёма описаны в
[docs/PROTOCOL.md](docs/PROTOCOL.md).

## Настройка

Имя сети и пароль впишите в `.env` (шаблон — `.env.example`), затем пересоберите
и перепрошейте плату: значения вшиваются в прошивку на сборке. Подробности в
[docs/WIFI.md](docs/WIFI.md).

Всё, что зависит от конкретной панели, лежит в [Config.h](include/Config.h):
пин данных, размер матрицы, тип ленты, яркость, бюджет питания и задержка
демо-последовательности. Задержку можно менять и в рантайме через
`DemoSequence::setStepDelayMs()` — это точка входа для будущего удалённого
управления.
